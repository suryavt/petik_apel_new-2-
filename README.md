# Aplikasi Wisata Petik Apel

Aplikasi Wisata Petik Apel merupakan aplikasi berbasis web yang dikembangkan menggunakan Django. 
Aplikasi ini digunakan untuk memberikan informasi mengenai wisata petik apel serta menyediakan 
fitur booking/pemesanan bagi pengguna.

## Teknologi yang Digunakan

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap

## Struktur Project

Project utama terdiri dari beberapa bagian:

- `booking/` : aplikasi Django untuk mengelola fitur booking.
- `petikapple/` : konfigurasi utama project Django.
- `templates/` : template halaman aplikasi.
- `static/` : file CSS, JavaScript, gambar, dan aset lainnya.
- `db.sqlite3` : database SQLite.
- `manage.py` : file untuk menjalankan perintah Django.
- `requirements.txt` : daftar library/dependency yang dibutuhkan.

## Persyaratan

Sebelum menjalankan aplikasi, pastikan komputer sudah memiliki:

- Python 3.x
- pip
- Web browser (Google Chrome, Mozilla Firefox, atau Microsoft Edge)
